# AI Personal Career Mentor

A Django web application for career recommendations, learning roadmaps, resume feedback, AI mock interviews, a career chatbot, job-description skill matching, and progress tracking.

## Tech stack
- Python + Django
- SQLite
- HTML, CSS, JavaScript
- Optional OpenAI API integration
- pypdf for extracting text from PDF resumes

## Requirements
- Python 3.10+
- VS Code (recommended)
- Internet connection only for installing dependencies and optional AI API calls

## Run on macOS (zsh) or Linux

1. Unzip the project and open the `ai_personal_career_mentor` folder in VS Code.
2. Open the integrated terminal and create a virtual environment:

   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```

3. Install dependencies:

   ```bash
   python -m pip install --upgrade pip
   pip install -r requirements.txt
   ```

4. Create your local environment file:

   ```bash
   cp .env.example .env
   ```

   The app works without an API key using local fallback responses. For generative AI, open `.env` and set `OPENAI_API_KEY` to your own key. Never commit `.env` or share your key. API usage may incur charges.

5. Create the database tables:

   ```bash
   python manage.py migrate
   ```

6. (Optional) Create an admin account:

   ```bash
   python manage.py createsuperuser
   ```

7. Start the development server:

   ```bash
   python manage.py runserver
   ```

8. Open http://127.0.0.1:8000/ in your browser. Register an account, fill out your profile, then explore the dashboard.

## Feature guide
- **Career recommendations:** uses a transparent keyword-based baseline against a small built-in role catalogue.
- **Learning roadmap:** creates roadmap tasks using the configured AI provider, or a local fallback when no key is set. Mark tasks complete to update the dashboard.
- **Resume analyzer:** extracts text from a PDF in memory and requests feedback. The PDF itself is not stored. If AI is configured, extracted text is sent to that provider.
- **Mock interview:** generate questions and submit answers for feedback. Attempts are saved in SQLite.
- **Career chatbot:** sends career questions and basic profile context to the configured AI provider.
- **Job description matching:** compares skill keywords and shows overlaps and gaps; this is a baseline, not a semantic hiring score.
- **Progress dashboard:** tracks roadmap task completion and recent interview practice.

## Important notes
- This is a learning/demo project. Career suggestions and matching scores are not professional hiring assessments and do not guarantee employment.
- Do not upload confidential documents or personal information you do not want processed.
- For deployment, set `DEBUG=False`, use a strong `DJANGO_SECRET_KEY`, configure production `ALLOWED_HOSTS`, HTTPS, secure cookies, logging, backups, and a production database. Do not use Django's development server in production.
- The AI integration is optional. Without an API key, the application uses local fallback responses; those fallback responses are not generated by AI.
- The app uses Django's built-in authentication. Each registered user sees their own profile, roadmap tasks, and interview attempts.
